- #1 Infraestrutura de registro e métricas: O tempo-build.sh misturava a saída do Gradle com o tempo medido. Achei ao ler o CSV gerado e resolvi mandando a saída do Gradle para o stderr.
- #7 Cliente do backend: Sem ocorrência relevante: o template do React Native já libera HTTP no build debug, e o cliente já nasceu enviando o Content-Type JSON só nas requisições com corpo, que foi o problema que apareceu no Kotlin.
- #9 Boas-vindas e decisão de sessão na abertura: O Jest não importava o React Navigation, que é publicado em ESM; resolvi com `transformIgnorePatterns`. O mock do safe-area-context exporta em `default`. O teste do ViewModel entrava em laço porque o repositório falso era recriado a cada render e mudava a dependência do `useEffect`. Conferi também um espaço antes da vírgula do título: ele continua sem `letterSpacing`, então vem do desenho da fonte.

## Notas de uso do framework

- #1 Infraestrutura de registro e métricas: Esta issue não envolveu código do app: montei o registro da pesquisa. O preço em reais e as datas ISO viraram funções de formatação comuns, e o token entra em cada chamada protegida pelo chamador autorizado, que também renova a sessão. As listas paginadas são lidas pelo campo data; o meta não é usado porque nenhuma tela carrega mais de uma página.
- #9 Boas-vindas e decisão de sessão na abertura: Tela, ViewModel (hook), tema, componentes, navegação, cliente HTTP e sessão ficaram em `src/`, comuns às duas plataformas. O trabalhoso foi configurar o Jest para os pacotes ESM do React Navigation e para os módulos nativos.
